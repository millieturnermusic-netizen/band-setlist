# Millie's in a Band - Rehearsal Setlist & Stage Cue

An interactive live setlist, chord sheet, role-filtered notes, and rehearsal playback web application.

## Features
- **Instrument Petal Flower**: Role switcher for Composer, Guitarist, Keyboard, Bass, Drums, Singer, and Audio Tech.
- **Setlist Management**: Clean setlist view with drag-and-drop song ordering.
- **Dual-Lane Lyrics & Chords**: Auto-scroll with adjustable tempo, transposer, and karaoke highlighting.
- **Multi-Track Audio Engine**: Master audio playback and real-time groove synthesizer (drums, bass, and chords matching song key & BPM).
- **Responsive & Offline-First**: Works on Mac, PC, iPad, and iPhone.

Hosted with GitHub Pages.
